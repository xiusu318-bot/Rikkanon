## 🎉 v1.2.0 重大版本更新说明

**`v1.2.0` 是一次核心机制重构级的重大更新**，正式带来了全套 **「高级提示词模式（提示词预设组装 & 新版世界书引擎 & 深度正则）」**。

本次大更新的核心思路是 **「最大程度化自由构造与编排 API 请求体」**：彻底打破固定拼接系统提示词的暗箱模式，将发往大模型的所有消息要素（角色系统提示词、长期记忆、工作区与工具提示词、世界书条目、聊天历史、思维链与签名、后置指令乃至原生 JSON 消息元素）全部拆解为平权、可自由拖拽排序与按 `@D` 深度注入的积木块；并支持通过 **JSON 模式** 直接在请求体任意位置注入自定义结构（例如精细控制 `cache_control` 显式缓存断点）。

## ✨ 二开定制功能概览

详细的功能说明请参阅 👉 [**`MOD_DOCS.md`（Rikkanon 功能说明文档）**](MOD_DOCS.md) 与 [**`ADVANCED_PROMPT_DOCS.md`（高级提示词模式专项文档）**](ADVANCED_PROMPT_DOCS.md)。

### 1. 🧩 高级提示词模式：最大化自由构造 API 请求体（v1.2.0 大更新）
- **最大化自由请求体编排**：
  - 将原本由客户端暗箱拼接的各路提示词全部暴露到预设轨道上。提供模块总开关（位于标题同行右侧，滚动时自动淡出，关闭后页面收起隐藏且原样返回消息）与预设独立开关。
  - 采用 **「弹窗内保存草稿 + 外部点击『保存预设』落盘」** 的双保存防误触机制，防止滑动列表时手滑打乱顺序。
- **6 个平权内置模块 (`📌`) & 酒馆标准位置与深度注入**：
  - 内置 `World Info (before)`、`Char Description`（纯助手自身系统提示词）、`记忆`（仅开启记忆时注入）、`工作区提示词`（承接工作区与工具附加提示，仅启用时注入）、`World Info (after)`、`Chat History` 6 个模块，支持点击调整名称、开关、角色与位置；
  - 对齐酒馆（SillyTavern）标准的位置与深度体系：**`相对 (RELATIVE)`**、**`聊天中 (IN_CHAT @D)`**、**`附着到已有消息 (ATTACH_TO_MESSAGE @D)`**，支持直接导入酒馆预设 JSON；
  - 新增单块开关 **「按预设发送工具调用」**：开启后在连续工具调用中将该工具调用视为普通聊天历史最后一条，允许将后置提示词或 `@D 0` 块排到工具调用之后。
- **自定义提示词块：常规三段式思维链回传 ⇄ 原生 JSON 模式（以「显式缓存」为例）**：
  - **常规模式**：支持 `系统`、`用户`、`AI` 及特殊空白角色 **`？`**（组装时自动跟随前一个模块合并进其正文）；提供 **正文 / 思维链摘要或明文 (`reasoning`) / 思维链签名 (`reasoningSignature`)** 三段式编辑栏，自动适配 Claude、Gemini、OpenAI 及开源模型的思考字段。
  - **JSON 模式（双向智能互通）**：支持与常规模式一键互转并保留自定义顶层字段。开启 JSON 模式的块经宏展开后，**原封不动作为独立数组元素并入底层 API 请求的 `messages` / `contents` 数组内**。例如在任意位置或 `@D` 深度直接构造带 **`cache_control` 显式缓存断点** 的消息块：
    ```json
    {
      "role": "user",
      "content": [
        {
          "type": "text",
          "text": "{{outlet::静态设定集}}\n以上为核心静态背景，请严格遵循。",
          "cache_control": {
            "type": "ephemeral"
          }
        }
      ]
    }
    ```
  - **预设块独立边界与 Claude 缓存断点保护**：Provider 层仅合并真实聊天历史的相邻同角色消息，预设块与 JSON 块始终保持独立元素不合并；Claude 自动定位「倒数第二条 `user` 消息」插入缓存断点时自动排除预设合成块，防止底部或 `@D` 预设块导致历史缓存每轮失效。
- **高性能世界书引擎 (Lorebook)**：
  - 支持 **🔵 常驻蓝灯** 与 **🟢 条件绿灯**（普通词、`/regex/flags`、4 种次要关键字逻辑、递归控制、`@@activate`/`@@dont_activate` 装饰器）；
  - 支持 **三档绿灯缓存策略**：默认 `STICKY_LOCKED_POSITION`（触发后持续激活并**锁定首次触发时的 `@D` 对话位置不变**直至下次压缩，最大化保护多轮 Prompt Cache）、`STICKY_FLOATING`、`DYNAMIC_NATIVE`；
  - 支持 **6 种注入位置**（角色定义前/后、`@D 系统/用户/AI`、`➡️ 锚点 {{outlet::名称}}`）与 `@D` 前后同角色双向正文合并；
  - 内置链式哈希检查点缓存与 Aho-Corasick 多模式关键字位图匹配，长对话与大世界书开启递归时增量扫描仅需毫秒级。
- **助手正则重构**：支持 **「仅修改发出」**、**「仅修改显示」**（默认双勾选，无损保留数据库原文）与 **「直接修改正文」**；作用范围扩展为 **`用户` / `助手` / `世界书`**，支持对齐酒馆的 **`最小深度 / 最大深度`** 过滤与分阶段按字符数缓存。

### 2. 🖥️ 工作区持久化交互式 PTY 多终端 (`workspace_terminal`)、顶栏窥屏小窗 & 沙箱兼容补丁
- **持久化交互式伪终端工具 (`workspace_terminal`)**：结合终端会话池扩展出供 AI 持续交互的伪终端工具（同时支持本地 PRoot 与远程 SSH 工作区）。终端按工作区共享，主对话、子代理、新开对话与人类终端 UI 共用同一终端池。
- **多终端管理与自关闭**：支持开启多个命名终端、按数字 `#id` 操控；支持在终端内输入 `exit` / `Ctrl+D` 退出顶层 Shell 后自动关闭标签页，或通过 `kill` / `kill_all` 参数关闭终端。
- **进程树状态感知**：快速识别顶层交互式 Shell 与前台活跃子进程，在命令结束回到提示符时及时返回，无需等待固定超时。
- **聊天页顶栏终端快捷胶囊与实时窥屏小窗**：在聊天页（含空白新对话）顶栏右侧展示极简终端角标 `[🟢 🖥 N]`，点击展开终端列表卡片面板或弹出实时窥屏小窗查看 40 行实时终端屏幕、发送命令或 `Ctrl+C`、新建或关闭终端。
- **工作区工具「启用」与「审批」分离控制**：在工作区详情页可对 5 项工作区工具（`read_file`、`write_file`、`edit_file`、`shell`、`terminal`）分别独立控制是否启用以及调用前是否需要审批；同时保持工作区系统提示词静态以保护多轮 Prompt Cache。
- **PRoot 沙箱 6 项运行环境兼容补丁**：支持共享内存挂载、不可读系统状态节点兜底、Node.js 网卡枚举兼容、`apt`/`dpkg` 防锁死与自动清缓存、轻量级服务启动兼容脚本以及 ARM64 JVM 与无沙箱浏览器环境变量注入。

### 3. 🤖 子代理（Sub-Agent）独立模块、多模型绑定与分级权限控制
- **独立模块与多助手/多模型绑定**：
  - 子代理本质上是一条独立的普通对话，可共享同一工作区与终端池。
  - 支持通过复选框绑定 **1 个或多个助手**作为子代理（每个子代理拥有独立的模型、系统提示词、思考强度、MCP 与 Skills），支持在页面内快速新建子代理助手。
  - **标签长文本描述注入**：助手的「标签 (`Tags`)」支持多行长文本输入与点击编辑，自动注入子代理派发工具定义中充当职责说明（不注入易变模型名，避免换模型影响主代理缓存）。
- **子代理独立工具管理与双轨审批面板**：
  - 点击子代理右侧 `⚙` 可配置该子代理的单轮工具调用次数限制、5 项工作区工具独立开关（如配置只读子代理）、MCP、联网与记忆及 Skills。
  - 下方针对每个已开启的工具独立配置 **「用户审批」** 与 **「主代理审批」**（默认免审批直接执行；只开主代理审批时由主代理通过工具处理；只开用户审批时由人类在 UI 确认；双开时具备幂等防冲突保护）。
- **子代理全中断态通知（强插 Steer + 闲时唤醒）**：除正常完成外，当子代理触发待主代理审批、被用户手动停止或因接口异常中断时，均自动生成折叠通知条通知主代理。
- **子代理并发池、单轮步数限制、局部编号路由 (`sub_1`) 与主对话分支 (Fork) 自动克隆隔离**：
  - 支持配置同一主对话下的**子代理并发限制**与**单轮工具调用步数限制**；支持批量等待与 HTTP 429/503 指数退避重试。
  - 主代理统一使用局部代号（`sub_1`、`sub_2`）路由子代理；对主对话执行分支（Fork）时自动深拷贝独立子代理副本并重新映射 `sub_1`，兼顾历史上下文 Prompt Cache 与分支隔离。
- **主代理对子代理的 5 级控制权限**：涵盖 0 级（单次派发等待最终回复）、1 级（查看工具轨迹）、2 级（多轮追问与异步并发）、3 级（中途打断与停止）、4 级（删除销毁子代理）。
- **顶栏紧凑角标、展开列表面板与左侧抽屉树状主从跟随 UI**：顶栏右侧展示极简子代理状态角标 `[🟢 🤖 N]`，点击展开圆角列表卡片面板查看完整长标题与快捷操作，点选任意子代理即可弹出实时窥屏小窗；左侧抽屉以树状缩进（`├─ 🤖`）挂载在主对话下方。

### 4. ⚡ 流式控制、双层 Roll、全消息双模式编辑器、密钥代名词 & 模型多选删除
- **同轮多工具并发 & 免暂停中途插话（Steer）**：同一轮多个工具调用或多个子代理派发支持并发执行；在模型连续调用工具期间，用户无需暂停即可直接发送消息插话，下一轮步骤自动追加并响应。
- **双层 Roll 与单工具直接编辑**：点开任意工具步骤弹窗，支持直接修改工具 `input`（入参 JSON）与 `output`（返回文本），并提供「仅保存」、「重跑此工具并继续」、「从此步 Roll」三种操作。
- **整条助手消息双模式编辑器**：
  - **模式 1（可视化部件模式）**：卡片化展示并编辑所有思考、工具、正文部件，支持单步 Roll/重跑、上下移动、增删部件及修改底层字段。
  - **模式 2（底层 JSON 源码模式）**：查看与编辑整条消息在数据库中的原始 JSON 结构，支持原地覆盖或保存为新分支。
- **密钥代名词自动替换 & `ask_key` 询问密钥工具**：
  - 在「设置 -> 扩展 -> 密钥代名词」开启后，工具调用中包含已启用代名词时，执行层自动替换为真实值，且工具输出中若出现真实值会自动反向脱敏还原为代名词，避免敏感凭据进入模型上下文。
  - 开启本地工具「询问密钥」后，模型可在聊天流中弹出交互卡片供用户选择已有代名词或新建条目。
- **更新渠道编辑能力 & 渠道模型多选批量删除**：在提供商详情「模型」页长按模型卡片右侧 `⋮` 即可进入多选并勾选该模型（单击 `⋮` 仍为原删除菜单，卡片其余区域长按仍为拖拽排序），支持全选与一键批量删除。

### 5. 🎨 2.5.6 经典交互保留、记忆自动整理开关 & 滚动修复
- **会话配置实时跟随助手设定**：主对话与子代理对话实时跟随所属助手的最新模型、思考强度、搜索开关、MCP、Skills 与工具配置；切换助手模型后已有对话可直接按新模型继续运行。
- **保留 2.5.6 紧凑卡片与弹窗交互**：保留提供商 `+` 弹窗添加与经典详情页、MCP 底部弹窗配置、聊天页单层 `+` 面板以及一体式紧凑圆角卡片。
- **记忆新增「后台自动整理记忆」独立开关（默认关闭）**：在「助手详情 -> 记忆 -> 设置」中可独立控制是否开启后台自动整理，方便仅在对话中按需调用记忆工具或手动点击「立即整理」。
- **长对话上拉回跳修复 & 新聊天发送消息 ANR 修复**：通过编译期字节码补丁修复进入长对话后首次上拉偶发跳回页面底部的列表测量差值累加问题；移除生成时同步重测量自动滚动死循环，彻底解决新聊天发送第一条消息卡死闪退问题。
